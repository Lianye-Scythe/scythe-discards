# Chrome 設定頁方向品質基準

依據：使用者於本對話明確選擇「偏 Chrome 設定頁的風格」，並要求深淺色跟隨系統或 Chrome。此基準約束已選定的方向，不開啟新風格選擇。

- 主工作是調整卸載規則與例外；桌面使用固定位置的設定導覽、清楚標題、設定列與原生表單控制。
- 使用系統 UI 字型、克制的標題大小、藍色主要動作與中性表面。層次由間距、語意與群組建立。
- 一般／嚴格模式的差異及未儲存內容的後果在選擇當下可見；白名單、暫停和保護都有明確結果。
- 分頁清單顯示真實狀態與到期資訊；不以虛構的節省 GB 或百分比取代可驗證資料。
- 淺深色共享色彩角色；跟隨系統與手動覆寫都必須實際運作。
- 1440px、620px、380px 的四個功能目的地可操作；360px popup 可直接操作目前分頁。窄視窗保留所有控制及可見狀態，不出現文件水平溢出。
- 導覽為真正切換目的地，支援重新載入與上一頁；每次資料刷新維持搜尋、表單草稿及仍存在之控制的鍵盤焦點。
- 與實際 Chrome 設定頁同尺寸對照；設定內容約 680px 寬、單選為條列，開關與主要控制對齊。不以藍色、圓角或測試通過代替視覺完成度判斷。
- 三語皆保留清楚的導航、完整網站範圍與繼承原因；移除及復原結果可確認，較長英語不擠壓控制。紀錄上限、頁碼、範圍與清除結果一致。
- 二次元圖示保留金髮、向日葵草帽及綠色緞帶的角色辨識，透明邊緣乾淨；16px 仍有頭像輪廓，32px 以上可辨臉部。
- 原生語意標籤、可見鍵盤焦點、就近錯誤與操作回饋；狀態不單靠顏色辨識。焦點依控制類型處理：輸入框／選單貼齊邊線，按鈕／開關保留緊密外圈，導覽向內繪製。
- 空白、讀取、失敗、儲存中與暫停都使用真實狀態，不引入阻斷工作流程的風格展示或不必要的確認對話框。連線失敗時清楚標示資料已過期，提供可觀察的重試狀態。
- 在 360×600 的長網域／錯誤情境，焦點控制不得被頁尾或通知遮住；Undo 在聚焦或停留時保留，通知關閉後返回適當焦點。
- 繼承保護直接說明來源與可用的管理動作；長網域在 320px 仍可用鍵盤展開、讀取及選取完整內容，資料更新不關閉仍屬同一網站的展開狀態。斷線時恢復入口優先於舊成功提示，尚待復原的 Undo 不因無法操作而逾時。

驗證證據為實際載入擴充功能的畫面與流程；Windows 已安裝 Chrome 的獨立設定檔已列入實測；本基準不宣稱全面 WCAG 符合性、日常設定檔相容性或已證明記憶體效益。
