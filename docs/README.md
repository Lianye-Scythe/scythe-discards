## Repository layout

```text
src/                 Background adapter, policy, UI and locale catalogs
public/              Manifest template and shipping icon source
scripts/             Build, packaging and test launchers
tests/unit/          Policy, controller and i18n unit tests
tests/browser/       Chrome API, lifecycle and UI flows
docs/translations/   Translated project READMEs
docs/design/         UI maintenance guidelines
docs/images/         Published screenshots and their sources
```

`dist/` is generated by the build. Local reports and browser profiles are kept out of version control; CI retains its uploaded reports according to the workflow policy.

The tracked tree contains extension sources, tests and current maintenance documentation. Local tool context, working notes and unused artwork are covered by ignore rules. Earlier source revisions remain available through Git history and release tags.
